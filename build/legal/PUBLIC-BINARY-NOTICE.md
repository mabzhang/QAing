# Public preview binary notice

This QAing build is an Apple Silicon preview for macOS 14 or later. It is
ad-hoc signed and has not completed Apple Developer ID signing or notarization.
It is therefore published as a GitHub Pre-release, not as a production-signed
or Apple-notarized release.

The package contains no default or shared API keys. Users must supply their own
DeepSeek and Doubao SeedASR credentials in QAing Settings and are responsible
for provider terms, authorization, and usage charges.

Project documents, transcripts, application databases, Keychain exports,
credential files, logs, and model caches are not build inputs and are not
included in this package.
