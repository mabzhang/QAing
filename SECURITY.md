# Security policy

## Supported versions

Security fixes are applied to the current `main` branch and, when practical,
the latest `0.1.x` preview release.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** / Private Vulnerability
Reporting feature for this repository. Do not open a public issue containing
API keys, access tokens, transcripts, project documents, answers, absolute
local paths, or other sensitive data.

If private vulnerability reporting is unavailable, use the contact method in
the README only to request a private reporting channel. Do not send secrets or
confidential project content in the first message.

Include a minimal reproduction, affected version, impact, and any safe logs
that do not contain user content. Please allow a reasonable period for
investigation before public disclosure.

## Scope reminders

- Never test against another person's project data or provider account.
- Do not use real API credentials in a proof of concept.
- Avoid denial-of-service tests against cloud providers or public systems.
- The public preview binaries are not a production security guarantee.
