# QAing 0.1.7 — Internal Preview / 内部预览版

> Private internal build. Ad-hoc signed and not notarized by Apple. Not intended for public distribution.
> 私有内部版本。安装包采用 ad-hoc 签名且未完成 Apple 公证，不用于公开分发。

## 中文

### 本版重点

- 项目型资料库：按项目文件夹隔离资料、检索和会话历史。
- 简化“项目同步中心”：正常状态只展示资料是否可用、资料摘要与同步方式；异常和待处理项按需展开。
- 会话工作台：按项目恢复问答历史，支持单轮删除、项目清空和 Markdown 导出。
- 模拟问答助手：默认目标 30 条，超过 40 条需确认风险；证据不足时输出资料缺口，不为凑数编造答案。
- 新增中英文 GitHub README 与私有发布说明。
- 最低系统版本统一为 macOS 14，匹配本地语义运行时要求。

### 安装

1. 推荐下载 `QAing-0.1.7-arm64.dmg`，ZIP 仅作为备用。
2. 打开 DMG，把 QAing 拖入 Applications。
3. 从“应用程序”启动。
4. 首次打开可使用 Control/右键 → 打开，或在“系统设置 → 隐私与安全性”中选择系统提供的“仍要打开”。
5. 在应用内分别申请麦克风与系统音频权限。

不要关闭 Gatekeeper。ad-hoc 包升级后可能再次请求权限。

### 要求与限制

- 仅支持 macOS 14+、Apple Silicon（arm64）。
- DeepSeek、豆包 SeedASR 和首次语义模型下载需要网络。
- 当前不内置 PDF/Office/OCR/图片与资料型音视频的自动转换。
- 该版本未使用 Developer ID 签名，未 Apple 公证，也没有自动更新能力。

## English

### Highlights

- Project-scoped library: documents, retrieval, and conversation history are isolated by project folder.
- Simplified Project Sync Center: the healthy state shows readiness, an exact summary, and the sync policy; operational details expand only when needed.
- Conversation Workbench: restores history per project and supports deleting one round, clearing a project, and Markdown export.
- Simulated Q&A Assistant: defaults to 30 targets, requires risk acknowledgement above 40, and records evidence gaps instead of padding unsupported answers.
- Added parallel Chinese and English GitHub README files and private release documentation.
- Raised the minimum OS to macOS 14 to match the bundled local semantic runtime.

### Installation

1. Download `QAing-0.1.7-arm64.dmg` (recommended). The ZIP is a fallback.
2. Open the DMG and drag QAing to Applications.
3. Launch it from the Applications folder.
4. On first launch, use Control/right-click → Open, or the macOS-provided Open Anyway action under System Settings → Privacy & Security.
5. Request microphone and system-audio permissions separately inside QAing.

Do not disable Gatekeeper. An ad-hoc build may request permissions again after an upgrade.

### Requirements and limitations

- macOS 14+ and Apple Silicon (arm64) only.
- DeepSeek, Doubao SeedASR, and the first semantic-model download require network access.
- Built-in automatic conversion for PDF/Office/OCR/images and library-oriented media is not available yet.
- This build is not Developer ID signed or Apple notarized, and it has no automatic updater.
