# QAing 0.1.8 Preview 1

> Public macOS arm64 test preview. The package is ad-hoc signed and not Apple
> Developer ID signed or notarized. It is intentionally marked as a GitHub
> Pre-release rather than Latest.

## 中文

### 重要：API 凭据

安装包**不包含任何默认、共享、开发者内置或用户预置 API Key**。使用 DeepSeek 回答/模拟问答与豆包 SeedASR 语音识别前，请在 QAing 设置中填写你自己供应商账号的凭据。

### 系统与安装

- 仅支持 macOS 14+ 与 Apple Silicon（arm64）。
- 推荐下载 DMG，打开后把 QAing 拖入 Applications。
- 本包为 ad-hoc 签名且未经 Apple 公证。若 macOS 阻止首次打开，请使用 Control/右键“打开”，或系统设置提供的“仍要打开”；不要关闭 Gatekeeper。
- 首次本地语义检索可能需要下载固定版本 BGE 模型；不可用时会明确降级为关键词检索。
- 该模型不在安装包内。固定转换版本尚未单独发布许可证元数据；下载前请查看包内 `MODEL-PROVENANCE.md` 与上游条款。本预览版如实将其记录为来源许可缺口。

### 本版更新

- 简化项目资料库概览，把健康状态与技术流程分开。
- 项目级会话工作台：切换项目时恢复对应历史，可单轮删除、项目清空与 Markdown 导出。
- 模拟问答助手：默认 30 条，超过 40 条时显示耗时与证据稀释风险；证据不足改列资料缺口，不凑数。
- 公开包排除用户凭据、数据库、日志、项目资料、模型缓存、图片处理库和非 arm64 原生件。
- 包内提供 QAing、Electron/Chromium、ONNX Runtime 与直接运行依赖的许可证/来源说明。
- Electron 随附的 `libffmpeg.dylib` 按 LGPL-2.1-or-later 使用；完整许可、对应源码指针及替换/重新签名说明见包内第三方声明。

## English

### Important: API credentials

The package contains **no default, shared, developer-owned, embedded, or
preconfigured user API keys**. Enter credentials from your own provider
accounts in QAing Settings before using DeepSeek answering/simulation or
Doubao SeedASR transcription.

### System and installation

- macOS 14+ and Apple Silicon (arm64) only.
- Download the DMG and drag QAing to Applications.
- This package is ad-hoc signed and not Apple-notarized. If macOS blocks the
  first launch, use Control/right-click → Open or the system-provided Open
  Anyway action. Do not disable Gatekeeper.
- The pinned BGE model may be downloaded on first semantic use. If unavailable,
  QAing explicitly falls back to keyword retrieval.
- The model is not bundled. Its pinned conversion currently has no independent
  license metadata; review `MODEL-PROVENANCE.md` and upstream terms before the
  runtime download. This preview records the issue as a provenance gap.

### Highlights

- Simplified project-library overview with readiness separated from technical pipeline details.
- Project-scoped Conversation Workbench with restore, single-round deletion, project clear, and Markdown export.
- Evidence-bound Simulated Q&A Assistant: default 30; requests above 40 disclose time and evidence-dilution risks; unsupported targets become evidence gaps rather than fabricated padding.
- Public package excludes user credentials, databases, logs, project documents, model caches, image-processing libraries, and non-arm64 native files.
- Bundled legal materials cover QAing, Electron/Chromium, ONNX Runtime, and direct runtime dependencies.
- Electron's dynamically linked `libffmpeg.dylib` is used under LGPL-2.1-or-later; bundled notices include the full license, exact source pointer, and replacement/re-signing guidance.
